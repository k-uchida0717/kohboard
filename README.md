# KOH Trip Vlog Location Board

旅Vlogの「どこで・何を・どう撮るか」をボードにまとめて、撮影当日はスマホでチェックしながら撮れるWebアプリです。
Milanote の撮影プランニングボードから着想を得て作りました。

**▶ アプリを開く：** https://<GitHubのユーザー名>.github.io/kohboard/

## できること

- 旅ごとに **プロジェクト** を作り、撮影リスト・タイムスケジュール・ロケ地・持ち物を **ボード** で管理
- シーンごとに **ノート／チェックリスト／参考画像／リンク** のカードを並べる（ドラッグで並べ替え）
- 撮影当日は「**今日のショット 残り○件**」を見ながらチェック。カードに色ラベル（未撮影・撮影済み・要再撮）
- テンプレート付き（旅・キャンプVlog フルセット／日常Vlog／空）
- **オフライン対応**：一度開けば、電波がない場所でも使えます
- iPhone の「ホーム画面に追加」でアプリのように使えます
- 使い方ガイド内蔵（右上の「？」）

## データについて

- 入力した内容は **使っている端末のブラウザの中だけ** に保存されます。サーバーには送られません。
- 端末を移るとき・バックアップするときは、右上の「▼書出」でファイルにして、「▲読込」で取り込みます。
- ブラウザのサイトデータを消すと中身も消えるので、大事なプランは書出しておいてください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JavaScript を1ファイルに） |
| `sw.js` | オフライン対応（Service Worker） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `icons/` | アプリのアイコン |

外部ライブラリは使っていません（書体のみ Google Fonts）。`index.html` をダブルクリックしても動きますが、オフライン対応は `https://` で開いたときだけ有効です。
